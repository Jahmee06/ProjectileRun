ACTIVE PROJECT


What is this?
I’m a Computer Science student at UCF and I built this 2D space game to see if I could actually use what I’m learning in Physics 1 and Calculus 2 for something cool. Instead of just making a basic game where things move in straight lines, I used a real physics engine called Pymunk to handle the rotation and momentum. It makes the ship feel way more realistic because you can't just stop instantly since you have to actually drift.

How I built it
If you check out my testing file, you will see a lot of the same logic and comments. I used a modular workflow for this because I’m still learning and I didn’t want to break my whole game every time I tried something new. I would build the physics or the music or the sprites in their own separate test files first. Once I knew a feature worked perfectly and wasn’t going to crash, I would bring that code over into the main script. It kept everything organized and saved me a ton of time on debugging.

The Goal
The point of the game is to dodge incoming fireballs while mastering the physics-based steering. It is definitely a challenge because the momentum forces you to plan your moves a few seconds ahead of time.

Controls
You use W for forward thrust and S for braking or reversing. A and D rotate the ship left and right.

What I am adding next
I am working on a leveling system right now. I want the fireballs to start off slow so you can get the hang of the controls and then have them speed up the longer you stay alive. It will really test how well you can handle the physics once things start moving fast.
